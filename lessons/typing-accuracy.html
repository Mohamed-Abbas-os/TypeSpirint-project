Lesson 03

How typing accuracy is calculated.

Accuracy is not a personality trait. It is a count of how often the characters you typed matched the reference.

The simple rule

TypeSprint calculates accuracy as correct characters ÷ total typed characters × 100. If you have not typed anything, it does not invent a percentage. The result stays empty until there is meaningful data.

Corrections still teach you something

A corrected character can be useful evidence even if the final input is clean. Notice what happened: did you rush a familiar word, reach with the wrong finger or lose your place after punctuation? The typing test compares the live value against the reference and supports backspace so you can recover honestly.

Exercise: one error at a time

  1. Choose punctuation or numbers in practice mode.
  2. Type slowly enough to identify the first error.
  3. Pause and repeat only the troublesome word or symbol.
  4. Finish with a sentence passage and look for fewer repeated errors.
Accuracy improves when the correction becomes information instead of interruption.

FAQ

Does a correction erase the mistake?

The live passage shows the corrected final input, while the test history records the final correct and incorrect character counts used by the result formula.

Should I stop whenever I make an error?

Not always. Learn to recover smoothly, then choose a separate slow drill when a repeated error deserves attention.
