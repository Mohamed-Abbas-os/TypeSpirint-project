Lesson 10

Keyboard practice exercises for the skill in front of you.

Choose an exercise that isolates one demand, then return to a sentence so the movement can transfer.

Common words

Use short, familiar words to warm up rhythm. Repeat a small set twice, aiming for even spacing rather than maximum speed.

Punctuation

Practise commas, periods, quotes and dashes in short sentences. Pause enough to see the mark before you type it; punctuation is part of the meaning.

Numbers

Type dates, times, prices and short sequences. Keep the eyes on the reference and let the number row or keypad choice match your real work.

Advanced vocabulary

Choose words that slow you down without becoming a dictionary exercise. Type the word, notice its shape and use it in a sentence if the spelling is unfamiliar.

Programming text

Code practice adds symbols, indentation and repeated characters. Use the programming category untimed first, then take a short test when the pattern feels stable.

Exercise: the three-lane session

  1. Two minutes of the weakest category.
  2. Two minutes of a normal sentence.
  3. One timed test to see what transferred.

FAQ

How long should an exercise be?

Short enough that you can repeat it with attention. Two focused minutes can be plenty for a targeted drill.

Should I use custom text?

Yes, when the text represents a real task or a pattern you want to revisit. Avoid entering confidential material.
