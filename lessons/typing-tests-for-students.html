Lesson 09

Typing tests for students should create feedback, not labels.

A test is a snapshot of one session. Pair it with practice time and a goal the student can influence.

Set the context first

Explain the duration, the five-character WPM standard and the role of accuracy before starting. This makes the number less mysterious and keeps the activity about learning.

Use a two-part session

Start with an untimed exercise that matches the class goal, such as punctuation or common words. Follow it with one short test. Compare the experience and the accuracy, not only the top speed.

Offer choice where possible

Students can choose between passages or a difficulty that feels challenging but reachable. A custom passage can connect practice to a current topic, provided no sensitive information is entered.

Exercise: reflect in one sentence

After a test, ask: “What will you change on the next attempt?” A concrete answer—look ahead one word, soften the hands, pause after punctuation—is more actionable than a score alone.

FAQ

Should students compare scores?

Comparison can be motivating for some learners, but a personal-best or process goal is often more useful and inclusive.

Can teachers use saved history?

TypeSprint history is local to the browser and is not a classroom reporting system. Any school workflow should use a separately reviewed tool and policy.
