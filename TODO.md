# TypeSprint acceptance checklist

- [ ] **Static website shell and responsive navigation:** The site runs as a static website without a backend, paid API, subscription, registration or authentication; uses HTML5, CSS3, vanilla JavaScript ES modules, JSON passages, localStorage and relative asset paths; provides a professional responsive light/dark theme, TypeSprint branding, tagline, header navigation, mobile navigation, accessible focus indicators, readable typography, touch-friendly controls and reduced-motion support across approximately 320, 375, 430, 768, 1024 and 1440 pixel widths.
- [ ] **Homepage and internal information architecture:** Homepage includes the required hero headline/supporting text, Start Typing Test CTA, WPM/accuracy explanation, test preview, sections for test start, difficulty, lessons, daily challenge, WPM calculation, accuracy tips, FAQs and latest resources; internal links connect relevant pages and every promised functional control works.
- [ ] **Functional typing test:** Test settings support 15, 30, 60 and 120 seconds; Beginner, Intermediate and Advanced difficulty; Common English words, Everyday sentences, Punctuation practice, Numbers practice, Advanced vocabulary, Custom text and Programming-related text categories. The browser typing engine renders immutable reference characters, highlights current/correct/incorrect states, tracks elapsed/countdown timing from the first valid typing action or explicit start, prevents duplicate timers, handles deletions/corrections and paste consistently, supports pause/cancel/restart/retry, and ends on timeout or completion without accidental passage editing.
- [ ] **Typing metrics and results:** Use one documented five-characters-per-word formula; calculate gross WPM, net WPM, accuracy, correct/incorrect/total typed characters, elapsed duration and any optional consistency metric correctly, safely handle empty input, announce results accessibly, show personal-best comparison and working retry/another-duration/client-side-share actions without uploading private data.
- [ ] **Practice mode and passages:** Separate practice page includes beginner, common words, sentence, punctuation, number, advanced, custom text and short daily challenge modes; practice has no countdown, tracks current-session progress and feedback, and uses original or appropriately licensed passages.
- [ ] **Daily challenge:** Challenge selection is deterministic from the current date without a date API; title/instructions/passage render; WPM and accuracy track; repeated attempts are allowed; local personal best is saved; the UI does not claim a global verified leaderboard.
- [ ] **Local progress dashboard:** localStorage stores best WPM, recent results, best accuracy, total completed tests, theme, preferred duration/difficulty and daily challenge progress; UI provides recent history, personal-best statistics, progress visualization, clear-history, CSV export and reset-all-data; storage failures/corruption are handled gracefully; copy explains browser-only storage, clearing data and lack of cross-device synchronization.
- [ ] **Original educational content:** Provide dedicated useful pages for improving speed, WPM, accuracy, finger placement, touch typing beginners, practising without looking, common mistakes, daily routine, students and keyboard exercises. Each has an original introduction, explanations, practical examples, actionable exercises, descriptive headings, relevant internal links and FAQs where useful; avoid keyword stuffing, fabricated statistics, testimonials, reviews and endorsements.
- [ ] **SEO and static-hosting files:** Provide unique titles/meta descriptions, canonical configuration, semantic heading hierarchy, descriptive internal links, Open Graph metadata, favicon, robots.txt, sitemap.xml, custom 404, lesson breadcrumbs, accurate visible-content structured data only, repository-subpath-safe relative paths and a synchronized manus-routes.json.
- [ ] **AdSense preparation and policy pages:** AdSense placeholders are disabled by default, configurable from a documented location and never placed beside/over typing controls or inside passages; no fake publisher ID, fake ads.txt, ad-click prompt, tracking script or approval/revenue guarantee. Include About, Contact, Privacy Policy and Terms of Use pages explaining browser storage and privacy limitations.
- [ ] **Performance and maintainability:** Keep JavaScript modular, dependencies minimal, passage rendering efficient, calculations lightweight, timers/listeners cleaned up, mobile virtual keyboard usable and no layout-blocking animations; provide maintainable project structure and honest documentation of boundaries.
- [ ] **Deployment and testing documentation:** Provide README with repository setup, local testing, production deployment, final-site URL configuration and AdSense-after-approval checklist; provide TESTING.md covering typing engine, storage, navigation, mobile menu, themes, direct page refreshes, assets/links, console errors, no-backend operation and disabled-ad behavior; include a suitable GitHub Actions workflow when supported.
