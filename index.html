How WPM works

Speed is useful when accuracy can keep up.

TypeSprint uses a familiar five-character word standard. Gross WPM measures the pace of all typed characters. Net WPM subtracts the rate of incorrect characters, so a fast result with lots of corrections does not look artificially strong.

Questions, answered

Before you start

Does TypeSprint save my typing history?

Only on this browser, using localStorage. Nothing is uploaded, and clearing browser data can remove the saved history.

How is accuracy calculated?

Accuracy is correct characters divided by total typed characters. Empty input safely reports no meaningful percentage.

Can I practise without a timer?

Yes. Practice mode is untimed and gives session feedback as you type.
